# Setup Bench

Tailored setup guides for electric guitar, acoustic guitar and electric bass. Runs on your computer, and you use it from the iPad over Wi-Fi. Needs only Python 3 (no packages, no API keys).

## Run it

Windows (PowerShell), from this folder:
```powershell
py server.py
```

macOS / Linux:
```bash
python3 server.py
```

On the iPad (same Wi-Fi), open **http://setupbench.local:8000** in Safari. The server announces that name on your network itself, so there's nothing to set up on the router or the iPad. If the name doesn't load, use the numeric address the server also prints (e.g. `http://192.168.1.23:8000`).

On Windows, allow Python through the firewall on **private networks** the first time it asks. In Safari, tap Share → **Add to Home Screen** for a full-screen app icon.

### Address options

| Command | iPad address |
|---|---|
| `py server.py` | `http://setupbench.local:8000` |
| `py server.py 80` | `http://setupbench.local` (no port) |
| `py server.py --name guitars` | `http://guitars.local:8000` |
| `py server.py --no-name` | numeric address only |

Port 80 gives the cleanest address. If the server says port 80 is in use, something else on the PC has it; stick with the default.

## Updating

```powershell
git pull
```
Then restart the server (Ctrl+C, then `py server.py`).

## Using it

1. **Create an account** (stored on your computer, in `setupbench.db`).
2. **Fill in My toolbox:** tick every tool you own. Each guide flags any required tools you're missing.
3. Pick **Electric Guitar**, **Acoustic Guitar** or **Electric Bass**, then search the **model library**:
   - **Your instrument:** from the owner's Instrument Info sheet.
   - **Saved:** specs someone checked and saved on this server.
   - **Common model:** typical factory specs for popular models.
   
   Not listed? Choose **Enter specs myself**.
4. **Check the specs.** Fields marked **Check** are estimates or vary between versions. Scale length and radius have an **Other** option for any length, in inches or mm.
5. **Generate setup guide.** Your checked specs are saved to the library, so that model is listed next time.
6. Check off steps as you go, and record what you set in the **Setup log**.

## Notes

- **Your data** (accounts, instruments, logs, toolbox, saved models) lives in `setupbench.db` next to `server.py`. Copy that file to back it up. `git pull` never touches it.
- **Security:** this is meant for your home network. It uses plain HTTP, so don't expose the port to the internet.

## Files

- `server.py`: web server and JSON API (accounts, toolbox, instruments, model library)
- `mdns.py`: announces `setupbench.local` on your network so the iPad can use a name instead of an IP
- `data/models.json`: the starter model library, generated by `tools/build_models.py` (edit that script, then run it)
- `data/options.json`: every spec option, shared by the form and the library builder
- `js/guide.js`: the guide generator (setup logic and target numbers)
- `js/tools.js`: tool catalog and per-guitar tool requirements
- `js/app.js`: screens, form, model picker, toolbox, setup log
- `js/data.js`: bridge-model notes, factory-target overrides, length parsing
